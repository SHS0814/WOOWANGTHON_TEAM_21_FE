# WOOWANGTHON_TEAM_00_FE

Expo (React Native + TypeScript) 앱. 어르신/보호자 역할을 한 앱에서 분기한다.

## 실행

```bash
npm install
npx expo start          # Expo Go 또는 개발 빌드
npx tsc --noEmit        # 타입 검사
```

## 현재 상태: 화면 골격 (모의 데이터)

- **서버와 AI가 아직 연결되지 않았다.** 모든 판독 결과는 모의 데이터이고, 화면 맨 위에 항상 **"모의 판독 (실제 AI 아님)"** 띠가 보인다
- 복약 시간 알림은 아직 없다. 띠의 [개발] 버튼 → "지금 약 시간 시뮬레이션"으로 질문 화면을 띄우고, 화면에 **"시뮬레이션"** 표시가 나온다
- 개발 도구에서 다음 판독 결과(정상 / 애매 / 칸 그대로 / 이중 의심), 무응답 진행, 역할 바꾸기를 고를 수 있다
- 카메라를 쓸 수 없는 환경에서는 사진 없이 진행한다 (모의)

## 구조

| 경로 | 내용 |
|---|---|
| `src/app/` | expo-router 화면. `elder/` 어르신(E1~E8), `guardian/` 보호자(G1~G8), `role.tsx` 역할 선택, `dev.tsx` 개발 도구 |
| `src/api/` | 데이터 접근의 유일한 지점. `client.ts` 인터페이스, `types.ts` 임시 타입, `mock.ts` 모의 구현 |
| `src/components/` | 큰 버튼, 카메라(가이드 틀), 약통 격자, 모의 띠 |
